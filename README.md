# SASAGo3! — 사사 고3 키우기

세종과학예술영재학교 고3 육성 시뮬레이션입니다.
Vite + React로 구성하고, 저장소에 제공된 캐릭터·낮·밤 PNG를 사용합니다.

## 실행

Node.js 20.19+ 또는 22.12+ 환경에서 실행합니다.

```sh
npm install
npm run dev
```

안내되는 로컬 주소로 접속하세요. 배포용 파일 생성은 `npm run build`,
빌드 미리보기는 `npm run preview`, 테스트는 `npm test`입니다.

## 현재 구현 범위

- 첫 방문 시 이름 입력과 남녀 캐릭터 선택
- 기숙사 메인 화면과 작은 화면용 세로 배치
- 월~토 활동 선택, 장소·사유 신청, 미신청 변경 취소
- **한 주 시작: 활동이 순서대로 반영되어 능력치가 바뀌고 다음 주로 진행**
- 주간 결과 팝업과 기록 화면(주별 변화량·안내 문구)
- 이번 주 할 일 체크, 능력치 표시, 캐릭터 대사
- 주간 일정이 표시되는 월간 달력, 날짜 기반 D-day
- 알림장, 가이드, 프로필 설정, 낮·밤 배경 전환
- 브라우저 자동 저장과 수동 저장, 새로고침 후 복원

## 주간 결과 계산

`src/systems/week.js`의 `resolveWeek`가 월~토 활동을 순서대로 적용하고, 일요일은 자동으로 휴식합니다.
무작위 요소는 없습니다.

- 활동별 변화량은 `src/data/activities.js`의 `effect`에 정의합니다.
- 학습 능력치(수학·물리·서술력·구술력) 증가량은 학습 효율에 비례합니다.
  효율은 `1 + (집중력 - 50) / 200`이고, 스트레스 70 이상이거나 건강 30 미만이면 각각 20% 줄어듭니다.
- 같은 활동을 3일째부터 반복하면 증가량이 하루마다 15%씩 곱해져 줄어듭니다.
- 능력치는 0~100으로 제한되고, 주가 끝나면 반올림해서 저장합니다.

용돈, 매점 구매, 아이템 사용, 학원 테스트, 스터디팀, 원서, 엔딩은 이후 구현 범위입니다.
날짜(2026-09-07 시작), D-day(모의 면접 2026-10-04), 할 일, 매점 상품은 예시 데이터입니다.

## 저장과 파일 구조

저장 키는 `sasago3-save-v1`, 저장 형식 버전은 2입니다. 버전 1 저장 데이터는 불러올 때 자동으로 옮겨집니다.
이름·캐릭터·배경·주간 일정·할 일·능력치·주간 기록을 현재 브라우저의 localStorage에 저장합니다.
계정 연동은 없으며, 브라우저 데이터를 삭제하면 저장 내용도 삭제됩니다.

- `src/App.jsx`: 화면 조립과 모달 전환
- `src/components/`: 화면 구성 요소, `modals/`: 팝업 내용
- `src/hooks/`: 저장, 일정 편집, 알림 메시지
- `src/systems/week.js`: 주간 결과 계산
- `src/data/`: 활동·능력치·아이템·일정·대사 데이터
- `src/game.js`: 초기 상태, 날짜 계산, 저장 검증·이전
- `src/styles.css`, `src/week.css`: 스타일

서체는 Google Fonts의 Noto Sans KR·Gowun Dodum을 사용하며,
네트워크 연결이 없으면 시스템 기본 글꼴로 표시됩니다.
