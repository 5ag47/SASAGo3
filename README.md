# SASAGo3! — 사사 고3 키우기

프로젝트 계획 보고서의 **2026.10.13 「스토리 및 개요 짜기」**를 바탕으로 만든 고3 생활 시뮬레이션 초안입니다. 원격 `main`의 기숙사·캐릭터·폰트 작업을 `ag_test`에 반영하고 일 년의 플레이 흐름을 연결했습니다.

## 실행

Node.js **22.12 이상**을 권장합니다.

```sh
npm ci
npm run dev
```

개발 서버 주소로 접속하세요. `npm run build`는 배포 파일 생성, `npm run preview`는 빌드 미리보기, `npm test`는 게임 로직 검증입니다.

이번 초안 검증 환경은 pnpm 11.25.0이며, 재현용 `pnpm-lock.yaml`도 포함했습니다. 동일한 버전으로 검증하려면 `pnpm install --frozen-lockfile`, `pnpm build`, `pnpm test`, `pnpm dev`를 사용하세요. 기존 npm 잠금 파일은 유지했습니다.

## 플레이

1. 이름·캐릭터·전공·특성을 고르면 과목과 기본 능력치가 자동 설정됩니다.
2. 겨울방학 알림에서 스터디에 참여합니다. 선택이 필요한 사건은 처리한 뒤 주를 시작합니다. 안내 알림은 읽지 않아도 과제가 자동 추가됩니다.
3. 전체 화면 오른쪽에서 요일을 고르고 **아침·1자·2자·연장, 하루 4칸**을 신청합니다. 아침은 참여/불참여, 1·2자는 학습/요양, 연장은 학습/잠을 선택합니다.
4. ‘한 주 시작하기’에서 계획을 확인하고 실행하면 과제·시험·건강·돈이 반영됩니다.
5. 여름 상담에서 수능을 해금하거나 수시를 준비하고, 9월 진학실에서 원서를 접수합니다.
6. 11월 면접 미니게임을 거쳐 12월에 대학 합격·재수·창업·알바 엔딩을 확인합니다.

겨울방학 1주, 3~11월 매달 4주, 12월 결과 1주로 **38주**를 플레이합니다. 능력치, 사건의 확률, 성적과 합격 기준은 초안용 가상 수치입니다.

- 아침스터디 과제·수면 부족 벌금, 청소·호실점검 벌점, 만성피로
- 인예주·강연·졸사·제주도·생일·추천서·방 배정·외부대회·추석·창의도전
- 여름 공부 장소별 비용·효율, 상담 후 수능 공부와 전형 해금
- 용돈·학원 비용·주말 알바·매점 간식·노트·의상 구매
- 대학·학과 선택 및 원서 기간, 평판에 따른 경쟁 정보 공개
- 3문항 면접 미니게임, 전형별 점수, 대학/재수/비진학 엔딩
- 주간 기록, 전체 학사 일정, 자동/수동 저장, 한 화면 모바일 배치, 음량·초기화·로그아웃 설정

자세한 구현 대응표와 초안의 제한은 [PROTOTYPE.md](PROTOTYPE.md)를 참고하세요.

## 데이터와 저장

- `src/data/courses.json`: 과목, 전공, 학점, 능력치, 평가 반영 비율
- `src/data/campaign.js`: 특성, 활동, 선택형 사건, 상점, 대학, 면접 문항
- `src/systems/campaign.js`: 학년 진행, 과제·시험·경제·입시 계산, 저장 검증
- `src/components/CampaignApp.jsx`: 캐릭터 생성, 저장, 설정 및 각종 창
- `src/components/GameScreen.jsx`, `game-screen.css`: 화면을 채우는 기숙사, 왼쪽 할 일·스탯, 중앙 캐릭터, 오른쪽 요일·시간별 신청
- `src/campaign.css`: 학년 플레이 화면과 반응형 스타일
- `src/systems/campaign.test.js`: 전체 학년 및 핵심 규칙 회귀 검증

자동 저장 키는 `sasago3-campaign-v1`, 저장 형식은 버전 2입니다. 이전 캠페인의 14칸 일정은 1·2자를 보존하고 아침 불참여·연장 잠을 추가해 28칸으로 자동 이전합니다. 기존 `sasago3-save-v1` 저장은 건드리지 않습니다. 새 캠페인은 겨울방학부터 시작하며, 기존 2학기 저장을 새 학년에 자동 변환하지 않습니다. 원본 PNG와 NeoDunggeunmo 폰트를 유지했고, 폰트 네트워크가 끊기면 시스템 글꼴로 표시됩니다.

기존 `game.js`, `systems/week.js`와 구성 요소는 이전 버전의 구현 참고 및 회귀 테스트를 위해 남겨두었습니다. 실제 진입점은 `App.jsx` → `CampaignApp.jsx`입니다.

## 브라우저 검증

선택적으로 Playwright와 Microsoft Edge가 있는 환경에서 개발 서버를 켠 뒤 `node scripts/smoke.mjs`를 실행할 수 있습니다. 별도 설치 위치는 `PLAYWRIGHT_MODULE`, 브라우저 채널은 `BROWSER_CHANNEL`로 지정합니다. 이 테스트는 격리된 브라우저를 사용하며 사용자의 저장 데이터를 바꾸지 않습니다.

시작·일정·알림·저장 복원·매점·성적표·모바일·과제 자동 추가·요일/시간 선택·설정·원서·면접·엔딩·제주도 일정 잠금을 검사하고 `.qa/`에 화면을 저장합니다.
