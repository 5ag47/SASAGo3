# SASAGo3! — 사사 고3 키우기

세종과학예술영재학교 고3 육성 시뮬레이션의 메인페이지 프로토타입입니다.
Vite + React로 구성하고, 저장소에 제공된 캐릭터·낮·밤 PNG를 사용합니다.

## 실행

Node.js 20.19+ 또는 22.12+ 환경에서 실행합니다.

```sh
npm install
npm run dev
```

안내되는 로컬 주소로 접속하세요. 배포용 파일 생성은 `npm run build`,
빌드 미리보기는 `npm run preview`, 저장 데이터 검증은 `npm test`입니다.

## 현재 구현 범위

- 첫 방문 시 이름 입력과 남녀 캐릭터 선택
- 시안 기반 기숙사 메인 화면과 작은 화면용 세로 배치
- 월~토 활동 선택, 장소·사유 신청, 미신청 변경 취소
- 이번 주 할 일 체크, 능력치 표시, 캐릭터 대사
- 주간 일정이 표시되는 월간 달력과 월 이동
- 알림장, 가이드, 프로필 설정, 낮·밤 배경 전환
- 브라우저 자동 저장과 수동 저장, 새로고침 후 복원
- 기록·가방·매점 미리보기
- ‘한 주 시작’ 버튼의 주간 계획 확인 팝업

사용자 요청에 따라 **주간 결과 계산과 시간 진행은 구현하지 않습니다.**
날짜(2026-09-07), D-day(모의 면접 예시 2026-10-04), 스탯, 용돈,
할 일과 매점 상품은 UI를 위한 예시입니다. 물리는 주요 선택 과목 예시입니다.
매점 구매, 아이템 사용, 로그인 서버, 수강신청, 스토리·엔딩은 이후 구현 범위입니다.

## 저장과 파일 구조

저장 키는 `sasago3-save-v1`입니다. 이름·캐릭터·배경·주간 일정·할 일을
현재 브라우저의 localStorage에 저장합니다. 계정 연동은 없으며,
브라우저 데이터를 삭제하면 저장 내용도 삭제됩니다.

- `src/App.jsx`: 온보딩, 메인 화면, 팝업과 입력 처리
- `src/styles.css`: 시안 기반 UI 및 반응형 레이아웃
- `src/game.js`: 예시 데이터, 달력 날짜, 저장 검증
- `src/game.test.js`: 저장 복원과 손상 데이터·날짜 경계 검증

서체는 Google Fonts의 Noto Sans KR·Gowun Dodum을 사용하며,
네트워크 연결이 없으면 시스템 기본 글꼴로 표시됩니다.
