# SASAGo3

기숙사에서 시작해 입시까지 한 해를 보내는 고3 육성 게임입니다. Vite + React를 사용합니다.

현재 개발 브랜치: `codex/sasago3-web-game`. main에서는 개발하지 않습니다.

공개 게임: **https://sasago3-play-20261027.sasago3.workers.dev/**. 실제 Google 로그인·일정 저장·새로고침 복구를 사용자 브라우저에서 확인했고 D1의 저장 버전 증가도 확인했습니다.

## 실행

Node.js 24 LTS를 권장합니다.

```sh
npm install
npm run dev
```

위 명령은 개인 브라우저 저장 모드입니다. 현재 실제 Google 로그인 설정은 Git에서 제외된 `.env.local`에 연결되어 있습니다. Google 로그인과 서버 계산 모드는 다음과 같이 실행합니다.

```sh
npm run dev:secure
```

**http://localhost:5173**을 엽니다. 같은 포트의 기존 dev 서버가 있으면 먼저 중지하세요. Firebase 설정을 처음 만드는 경우 [단계별 안내](docs/firebase-setup.md)를 보세요.

## 구현된 게임

- 캐릭터 그림·닉네임·특성·5개 전공 선택: 수학 / 물리 / 화학 / 생물 / 정보
- 겨울방학 튜토리얼 1주 + 3~12월 40주, 월~일 아침 자습·1자·2자 총 21칸 편성
- 요일 일정을 여러 날에 한 번에 복사, 고정 수업·행사 칸 보존
- 수강 과목 프리셋과 15개 과목의 이해도·퀴즈·중간·기말·수행 평가, 학점 가중 GPA
- 정보 전공 인공지능프로젝트, 교양선택 도시 환경과 도시 계획의 매주 프로젝트, 수학세미나 수리문항분석
- 마감 있는 과제·학원 숙제·졸업논문·자소서·원서, 시간 투자에 따른 자동 완료
- 스터디 지원·실패·참여 효과·불참 벌금, 선생님 친밀도·추천서
- 동아리·인예주·졸업사진·제주 탐사·생일·외부대회·추석·연합스터디
- 방학 공부 장소와 비용·효율, 고정 학원 칸과 자유 자습의 선택
- 면접 3문항 미니게임, 논술·창의도전·수능·종합 전형과 6종 결말
- 답변별 저장·복구와 면접 결과 검토, 손패·짝 모으기·고/스톱을 선택하는 8턴 카드 미니게임
- 용돈·아르바이트·매점 즉시 사용, 스트레스·체력·피로 관리
- 8개 단원의 첫 주 실습 안내, 편집 가능한 예시 일정, 순서 제한 없는 조작
- 브라우저 전체를 쓰는 기숙사 HUD, 휴대폰용 자습 패널, 한국 시간 07~19시 낮·그 외 밤 자동 전환
- UI 텍스트·이미지의 기본 드래그 차단. 입력 필드 편집과 향후 게임 드래그는 예외

과제 완료 보상에 현금은 없습니다. 수학·물리는 별도 전공이지만 원문에서 같은 수강 프리셋이므로 현재 과목 세트는 동일합니다. 제공되지 않은 ‘지혜의 길잡이’ PDF는 포함하지 않았습니다. 휴학 이후 복학 이야기는 아직 없으며 휴학 결말만 구현했습니다. 대학 이름이 나오는 전형은 게임용 가상 규칙입니다.

## 저장과 보안

과제와 실제 플레이 모듈을 추가·연결하려면 [과제·미니게임 편집 안내](docs/task-authoring.md)를 따릅니다. `npm run tasks:editor`는 로컬 편집기를 엽니다. 개별/그룹 모듈 지정과 변경 파일 내보내기를 지원하며 공개 게임·플레이어 DB와 분리됩니다. 현재 초안 목표의 미달 항목은 [재점검 기록](docs/draft-audit.md)에 구분했습니다.

- 로컬 모드: `sasago3-year-v1`에 자동 저장, 직전 백업·파일 내보내기/복원, 버전·범위 검증, 탭 충돌 감지
- 서버 모드: Google Firebase ID 토큰 서명·프로젝트·만료·Google 제공업체·계정 비활성화/폐기 검사, 서버에서만 결과 계산
- 서버는 UID·점수·저장 상태를 클라이언트로부터 받아 덮어쓰지 않습니다. 행동 명령·revision·중복 방지 키만 받습니다.
- 원자적 DB 저장, 요청 중복 방지, 사용자 기록 격리, Origin·CSRF 검사, 본문 크기·요청 빈도 제한
- 진단 보고서 다운로드 및 요청 ID가 포함된 구조화 서버 로그. 인증 토큰·이메일은 기록하지 않습니다.

공개 서버는 **Cloudflare Workers + D1**에 저장합니다. 로컬 개발 서버 DB는 `.local/game.sqlite`이며 별도 기록입니다. **Firebase는 Google 인증을 담당하며 게임 기록을 Firestore에 저장하지 않습니다.** 브라우저 방문 안내 기록은 계정·게임별로 분리하고 서버 점수와 연결하지 않습니다. 로컬 저장은 직접 수정을 막을 수 없으며 절대적인 보안이나 모든 부정행위 방지를 보장하지 않습니다.

## 검증과 빌드

```sh
npm run check
npm test
npm run build
npm audit --audit-level=high
```

서버용 배포 빌드는 공개 Firebase 설정을 넣은 `.env.local`을 준비한 뒤 `npm run build:secure`를 사용합니다. 이 빌드는 브라우저 저장으로 자동 우회하지 않습니다.

공개 서버 갱신은 `npm run cloud:deploy`, 실제 D1 저장 제약 확인은 `npm run smoke:d1`입니다. 저장소 전용 훅은 main 직접 커밋과 로컬 비밀 파일 커밋을 막고, `npm run check`에서 데이터·모듈 경계·미선언 변수를 검사합니다. 자세한 운영 범위는 아래 문서를 확인합니다.
