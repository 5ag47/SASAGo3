## 게임 규칙

- 핵심 표시 스탯은 건강, 집중력, 평판, 스트레스, 수학 능력이다. 교과·입시 계산에 사용하는 기존 과학·서술·구술 등 내부 능력은 보존한다.
- 집중력은 건강 − 스트레스의 소수 첫째 자리 값이다. 음수도 허용하며 범위는 -100~100. 별도 집중력 보상·소모는 적용하지 않는다. 건강·스트레스 효과 직후 다시 계산한다.
- 완료한 게임 주마다 수학 능력을 0.5 감소시킨다. 공부로 얻는 증가와 별도로 적용하며 0 미만으로 내려가지 않는다. 중간 미니게임 재개·입력·저장에는 감소하지 않는다.
- 학습량에 따른 추가 주간 스트레스·건강 소모는 `data/balance.json`의 `weekly.workStress`, `weekly.workHealth`에 있다.
- 과목별 자습·과제 1칸의 추가 부담은 `data/courses.json`의 `workload.health`, `workload.stress`이다. 첫 값은 학점과 과목 능력 계열에 따라 0.2~0.4 건강, 0.3~0.7 스트레스. 이후 과목 ID별로 조정할 수 있다.
- 주간 부담과 회복은 1년 시뮬레이션을 보며 함께 조정했다. 수학 감소를 추가한 대신 학습 기본 효율 1.05, 기본 주간 건강 소모 6·스트레스 7, 수면 건강 +5·스트레스 -3.5를 사용한다. 시기별 배율과 반복 회복 감소는 유지한다.
- 예상값은 상태 복사본에서 계산한다. 미니게임 버튼을 누를 때마다 과목별 1칸 부담을 중복 부과하지 않는다.

## 이벤트 데이터

`data/events.json`은 주요 선택·학사 이벤트, `data/life-events.json`은 생활 이벤트, `data/assignments.json`은 과제와 미니게임 설정, `data/calendar.json`은 실제 날짜 연결이다. 과목 ID도 기존 codex 카탈로그를 유지한다.

기존 스터디·졸논·과목 과제·시험·사진·제주·입시·기숙사 이벤트는 동등한 codex 정의를 사용하여 중복 발생을 피했다. test_dy의 귀가주, 나침반 활동, 분실물, 화학 퀴즈 후 이벤트는 `testdy_` 접두사의 새 ID로 옮겼다. 분실물 현금 지급은 공통 요구에 따라 제거했다. 화학 퀴즈 후 이벤트는 해당 과목 수강자만 받는다.

## 저장과 호환

CONTENT_VERSION: `2026.11.03-1`. 기존 codex 저장의 현재 집중력만 새 공식으로 변환한다. 과거 주간 기록·성적·완료 과제·재화는 재계산하지 않는다. 구버전의 대기 중인 2학기 재신청 이벤트는 해제하고 현재 수강을 유지한다. 이미 확정된 과거 전공·성적은 소급 변경하지 않는다.

test_dy의 옛 로컬 계정/저장과 codex의 연간 저장은 규칙과 키가 다르므로 자동으로 합치지 않는다. 기존 저장 데이터와 stash는 삭제하지 않았다. 이번 통합 화면은 `sasago3-year-v1` 저장을 사용한다.

## 실행·검증

- `npm run play`: 로컬 브라우저 저장으로 실행. `npm run play:login`: Firebase 로그인 및 로컬 저장 서버 실행.
- 기존 `.env`의 공개 Firebase 설정을 값 노출 없이 `.env.local`로 준비했다. 원본 `.env`는 그대로 유지한다.
- `npm run verify`: 콘텐츠·구조·린트·전체 테스트·서버 전용 빌드·과제 편집기 빌드·의존성 검사.
- `npm run balance:simulate`: 5전공 × 7전략 × 2시드, 총 70회 완주. 보고서 `.local/balance-report.json`.
- 브라우저 접근 승인이 거절되어 실제 로그인, 작은 화면의 시각적 배치, 브라우저 새로고침은 미확인. DOM 조작·저장 복원·서버 검증은 자동 테스트로 확인한다.
- 커밋·원격 push·배포는 수행하지 않는다.
