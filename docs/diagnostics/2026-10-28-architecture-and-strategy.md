## 문제와 변경

- 엔진·상태·화면 조립의 큰 분기와 서버의 별도 명령 필드 목록을 기능별 계약으로 나눴다. 상태 변환에는 단계 ID, 명령 실패에는 종류·처리 단계 로그가 남는다.
- 과제/달력의 변경 비교·충돌·파일 적용을 공유했다. 로컬 편집기에서 날짜·기존 일정 연결을 편집하고 ID 단위 변경 파일로 적용한다.
- 지원 방향 클릭의 점수 보너스 대신 학점·실제 활동 기록을 중심에 뒀다. 공통 제출·면접 단계에서 이전 준비는 보존하고 제출 자료는 고정한다.
- 교사 상담을 두 번 수행하고 다음 게임 날 추천서 검토를 받는다. 기록·관계 차이는 선형 비용/품질에 반영한다. 평가·비난 대사나 내부 부담 수치는 표시하지 않는다.
- 새 자소서가 공유 그룹을 상속하면서 보조 모델을 빠뜨리는 사례를 실제 일정 실행 검사로 발견했다. 개별 모듈의 support 설정으로 연결하고 실제 도전 비용·품질을 검사했다.
- 형식 미지정 교과 수행이 탐구에서 빠지는 부분은 일반 교과 기여0.5로 보완했다. 논문은 여러 활동 중 하나이며 단독 생기부 점수 기여는 최대5점이다.
