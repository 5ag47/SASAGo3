# 공개 화면의 Google 로그인 버튼 비활성화

증상: 사용자가 공개 주소에 접속했지만 Google 로그인 버튼이 회색으로 비활성화됨.

가설은 초기 확인 완료 처리의 변수 오류, Firebase 초기화 지연, 화면 클릭 차단 순으로 점검했습니다. 실제 `useGame` 훅과 React DOM 버튼을 jsdom에서 실행하는 `tests/ui/login.test.js`로 재현했습니다. 수정 전 `ReferenceError: alive is not defined`로 실패했습니다.

원인은 생존 여부 변수 `alive`를 메시지 타이머 효과 안에 선언하고 로그인 초기화 효과에서 참조한 것이었습니다. 완료 처리와 정리 단계가 오류를 내며 busy가 해제되지 않았습니다. 선언을 올바른 효과로 옮기고, 정리된 효과에서는 저장 조회를 시작하지 않도록 했습니다. 같은 회귀 테스트가 통과했습니다.

실제 Google 계정 선택·저장 복구는 사용자의 브라우저 확인을 별도로 받습니다. DOM 테스트 통과와 실제 로그인 성공을 구분합니다.
