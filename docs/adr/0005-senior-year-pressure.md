# ADR-0005: 시기 부담·컨디션 단계·월 예산·선택형 수능

- 상태: 채택, 콘텐츠 2026.11.02-1
- 사용자 결정: 키우기 장르의 주간 계획 → 실행 → 성장 구조는 유지한다. 현재 브랜치의 5전공·하루 3칸·생물다양성 미포함 결정을 유지한다. 고3다운 체감(시기마다 다른 압박, 되돌리기 어려운 결정, 돈의 제약)을 시스템으로 만든다.

## 문제

2026.10.28-3의 70회 비교에서 정상 전략의 주말 스트레스는 1년 내내 4~10, 집중력은 5월 이후 97에 고정됐다. 피로는 "회복 없는 공부"에서만 발생했다. 돈은 마지막 주까지 459,500원이 쌓였다. 수능 70점 이상은 "합격"으로 기록돼 수능을 준비하지 않은 전략도 10/10 진학 조건을 얻었다. 기획서의 "상담 이후에만 수능 활성화"는 `counseled` 플래그만 저장하고 읽지 않았다.

## 결정

공통 규칙은 `src/domain/senior-year.js`의 순수 함수로 모은다. 주간 실행(`week.js`), 계획 예상(`week-forecast.js`), 한 칸 미리보기(`activity-preview.js`), 화면이 같은 함수를 쓴다. 숫자는 모두 `data/balance.json`에 두고 `balance-validation.js`가 검사한다.

- **시기 부담(`seasons`)**: 0~40주를 빠짐없이 한 번씩 덮는 시기 구간이다. 학습 활동의 스트레스, 주간 생활 부담의 스트레스와 체력 소모에 `pressure`를 곱한다. 회복 효과에는 곱하지 않는다. 방학 구간(`vacation`)에만 아르바이트가 열린다.
- **회복 한도(`recovery`)**: 한 주의 회복 활동(수면·운동·게임·외출)은 `freeSlots`칸까지 온전히 효과를 낸다. 그 뒤 칸마다 `loss`만큼 줄고 `floor` 아래로는 내려가지 않는다. 쉬기만 해서 한 주의 부담을 전부 지울 수 없다.
- **컨디션 단계(`fatigue` 0~3)**: 지침 0.9 → 피로 0.75 → 번아웃 0.6의 학습 효율이다. 주말 체력·스트레스와 주중 최저 체력·최고 스트레스로 정한다. 회복은 한 주에 한 단계까지만 내려간다. 기존 `fatigue` 필드와 이름을 유지해 저장 형식은 그대로다. 빠른 편성의 회복 예산은 2단계(피로)부터 쓴다.
- **집중력 변동(`focus`)**: 주말마다 체력·스트레스·단계에서 정한 목표값 쪽으로 `drift`만큼 움직인다. 한 번 오르면 내려오지 않던 문제를 없앤다.
- **월 예산(`money`, `weekly.livingCost`)**: 매달 첫 주(1·5·9…주)에 용돈을 받고 매주 생활비를 낸다. 생활비가 모자라면 0원이 되고 스트레스 +3이다. 유료 여름 계획을 모두 고르면 실제로 잔액이 바닥난다.
- **선택형 수능**: 여름 상담에서 점검을 고르면 18주 `csat_decision`이 열린다. 준비를 고르면 `csat_study` 활동이 열리고 `flags.csatPrep`이 쌓인다. 수능은 합격이 아니라 시험 기록이다. 점수 = 실력×`csatAbilityWeight` + 대비 + 시드 변동 + 컨디션이고, `csatGrades`로 등급을 정한다. `csatMinimum`이 있는 전형(고대)은 종합 점수가 기준을 넘어도 최저 미충족이면 불합격이다. 38주 `regular_admission`(정시)은 `regularGrade` 이내면 합격이다. 상담을 건너뛰거나 수시 집중을 고르면 수능 미응시다.
- **결말**: 대학 진학을 고르면 가장 높은 순위의 합격 전형을 `ending.school`에 기록한다. 창업은 과학 70·평판 55 이상과 외부 수상 1회가 필요하다.

## 화면

자습 신청 제목 옆에 시기 이름을 표시하고 부담이 1.4 이상이면 따뜻한 색으로 바꾼다. 실행 버튼 위에 "주말 예상 체력·스트레스·단계"를 표시한다. 예상은 미니게임·이벤트·시험·난수를 빼고 계산하며 서버 결과를 확정하지 않는다. 능력치 카드의 피로 표시는 단계 이름을 쓴다. 잠긴 활동은 선택지에서 비활성화하고 이유를 툴팁으로 보여 준다. 진학실은 수능을 "시험"과 등급으로 표시하고 준비 상태를 보여 준다. 긴 상시 설명은 추가하지 않는다.

## 이전 저장

`senior-year-pressure` 변환이 한 번 실행된다. 이전 `fatigue: 1`(효율 0.65)은 2단계(피로)로 옮긴다. 18주가 지난 저장은 이전처럼 수능을 보도록 `csat: 'prepare'`를 넣는다. 이미 기록된 성적·과제·입시 결과(이전 방식의 수능 "합격" 포함)는 다시 계산하지 않는다. 새 게임은 `seniorYearVersion: 1`로 시작해 변환을 건너뛴다. 계획에 남은 잠긴 활동(학기 중 알바 등)은 주 시작 때 휴식으로 바뀌고, 실행 중에 만나면 휴식으로 대체한 이유를 기록한다.

## 검증 한계

`tests/domain/senior-year.test.js`가 시기 구간 검사, 같은 계획의 시기별 차이, 회복 한도, 단계 전환, 월 예산과 알바 잠금, 수능 해금·등급·최저·정시, 결말, 이전 저장 변환, 예상과 실제 실행의 방향 일치를 확인한다. 70회 비교 결과는 `docs/balance.md`에 있다. 실제 사람이 느끼는 압박의 적절함과 재미는 자동 정책으로 측정할 수 없다. 수능 등급 기준, 최저 기준, 시기 구분은 게임용 값이며 실제 입시 제도를 검증한 값이 아니다.
