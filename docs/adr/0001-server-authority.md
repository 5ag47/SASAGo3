# Google 인증과 서버의 결과 계산

상태: 사용자 선택으로 채택.

사용자는 공개 버전에서 Google 로그인과 서버 검증·저장·기기 간 복구를 선택했습니다. Firebase의 서명을 확인한 UID로 계정을 구분하고, 서버는 점수나 전체 저장을 받지 않고 행동 명령을 처리합니다. 공개 서버는 Workers + D1, 로컬 개발은 같은 규칙의 Node + SQLite를 사용합니다.

요청 재시도는 동일한 중복 방지 키를 유지합니다. 응답 유실로 성공 여부가 불명확하면 최신 상태를 읽기 전 새 명령으로 진행하지 않습니다. 브라우저의 튜토리얼 방문 기록은 성적·보상과 분리합니다.
