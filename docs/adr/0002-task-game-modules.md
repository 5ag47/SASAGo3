# 과제별 미니게임과 공유 그룹

상태: 사용자 지시로 채택.

과제는 자체 ID·진척도·마감·설정 스냅샷을 갖고, 실제 플레이는 등록된 코드 모듈에 연결합니다. 개별 과제의 모듈이 그룹보다 우선합니다. 서로 다른 그룹 설정의 충돌을 등록 순서로 덮어쓰지 않고 검증 오류로 처리합니다.

과제 정의와 그룹은 안정된 키를 가진 데이터이고, 도메인 모듈과 React 화면은 분리합니다. 같은 모듈을 여러 과제가 사용해도 `moduleData`는 과제별로 저장합니다. 발생한 과제의 설정은 동결하고, 동작을 변경할 때 새 모듈 버전 ID를 등록해 이전 저장을 유지합니다.

게임 서버는 행동만 받아 모듈로 검증합니다. 공통 처리기가 상태·완료·점수·효과를 검증하고 저장합니다. 클라이언트 코드 실행·완료 플래그·전체 저장 제출 경로는 만들지 않습니다. 개발자는 저장소의 검토된 코드와 등록 목록을 통해 모듈을 추가합니다.

예시는 순서 정리와 패턴 기억 두 개입니다. 기존 과제 내용을 임의로 늘리지 않고 모든 과제에 적용합니다. 모듈의 독립성은 개별 설정·그룹 충돌·중간 저장·서버 위조 요청·정상 완료 테스트로 검사합니다.
