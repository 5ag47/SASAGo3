# 원본 기획과 구현 대응

기준은 `planning-original.txt`와 이 대화의 후속 요구입니다. ‘구현’은 해당 규칙과 조작이 존재한다는 뜻이며 초보자 이해도·게임 밸런스·완전한 보안을 보증하는 표시는 아닙니다.

## 후속 UI 요구

최신 요구에 따라 과제 내용을 임의로 늘리지 않고 과제별 실제 미니게임 연결을 확장했습니다. 기존 과제 94개는 정의 데이터로 이동했고, 순서 정리·패턴 기억 두 예시를 전체 과제에 적용했습니다. 개별/그룹 지정·독립 진행·서버 행동 검증·중간 저장·코드/화면 등록·로컬 편집 도구를 제공합니다. 실제 과목별 상세 과제는 작성자가 정할 수 있습니다. 초안 목표의 미달과 검증 한계는 [재점검 기록](draft-audit.md)에 별도로 남깁니다.

뷰포트 전체 기숙사 화면, 낮/밤 한국 시간 자동 전환, 학습 능률·정상 컨디션 문구 제거, 종 알림, 왼쪽 아래 단일 달력, 불투명 패널, 드래그/텍스트 선택 차단(입력 예외), 주간 수치 표·활동 기록과 일기 문구 축소를 적용했습니다. 의사결정에 필요한 세부 효과는 요청해서 여는 상세 영역에 남겼습니다.

원본의 메모·물음표가 있는 항목은 게임용 규칙으로 구체화한 초안입니다. 실제 대학의 전형이나 학교 생활 규정을 재현·예측한다고 해석하지 않습니다.
