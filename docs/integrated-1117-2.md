## 개발자 모드

`npm run dev` 또는 로그인 없는 실행기로 연 뒤 주소에 `?developer=1`을 붙인다. 새 게임 화면 또는 설정의 **개발자 테스트 모드** 링크도 사용할 수 있다. 상단 코드 아이콘에서 조작한다.

- 일반 저장: `sasago3-year-v1`, 테스트 저장: `sasago3-year-v1-developer`.
- 일시 이동은 실제 일과·비용·마감·시험·결과를 계산한다. 미응답 선택은 정상 마감 규칙에 따라 처리되며 합격을 강제로 만들지 않는다.
- 이전 시점으로 이동하면 같은 초기 시드/프로필로 처음부터 재생한다. 이후의 테스트 선택·스탯 변경은 초기화된다.
- 집중력은 건강/스트레스에 종속되므로 직접 편집하지 않는다.
- 서버 모드는 테스트 명령을 받지 않는다. 배포 빌드에서 개발자 모드를 활성화하지 않는다.

## 애매하거나 미제공인 항목

- 2번의 선이수·졸업요건은 질문 형태이며 구체적인 과목/요건이 없다. 과목 JSON에 `prerequisites: []`, `graduationRequirement: null`로 명시하고 수강 제한은 추가하지 않았다.
- 지혜의 길잡이 PDF 미제공. 휴학 후 복학 이야기는 추가 기획 필요. 기존 휴학 엔딩 유지.
- 용돈 주/월 지급 초안 충돌은 1110 및 1번의 월 지급 유지.
- 초기 랜덤 학점은 4번의 기본 4.0으로, 픽셀 글꼴·BGM 제안은 5번의 가독성/음악 제거로 대체.
- 초안의 여러 미니게임 예시는 4번의 과제 미니게임 전부 제거에 따라 신규 과제로 구현하지 않았다.
- 수학/물리 통합은 기존 4개 카드 및 동일 과목 구성을 유지한다. 별도의 물리 저장 ID는 호환용이다.
- 미정 항목은 `integration-test-hannah.md`에도 연결했다. 실제 Google 로그인·공개 사이트 배포는 이번 화면 검증에 포함하지 않는다.

## 검증

- `npm run verify` 통과: 콘텐츠·구조·정적 검사, 전체 자동 테스트 306개, 서버 전용 게임·편집기 빌드, high 기준 패키지 보안 검사.
- 서버 전용 게임 빌드 및 과제 편집기 빌드 통과.
- `npm run balance:simulate`: 5개 내부 전공(구형 물리 포함) × 7전략 × 2시드 = 70회, 결과 `.local/balance-report.json`.
- 브라우저: 새 게임, 자동 이벤트/선택 확정, 로비, 메뉴 시간표, 연속 배정. 1366×768 및 1280×720에서 확인.
- 패키지 보안 검사: high/critical 0건, 기존 eslint/minimatch 개발 의존성의 moderate 경고 3건. 의존성 강제 변경은 하지 않았다. 최종 실행 로그는 `.local/verify-v2.log`.

시뮬레이션 통과는 실행 오류·저장 유효성 검증이며 모든 플레이 전략의 재미나 합격률이 완벽히 조정되었다는 뜻은 아니다.
