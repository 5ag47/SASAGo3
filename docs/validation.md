## 실제 브라우저 확인

콘텐츠 `2026.10.27-7`은 과제의 실제 미니게임 모듈·공유 그룹·작성 도구를 추가했습니다. 94개 기존 과제를 데이터로 옮겨 자동 생성분도 이벤트 집계에 들어가며, 이벤트 수 증가는 새 과제 내용을 지어낸 결과가 아닙니다. 모든 과제의 모듈 연결, 개별 우선·그룹 충돌, 독립 미니게임 상태, 단계·반복, 구버전 진척 보존, 위조 통과/점수 거절, 중복 행동, 패턴 정답 숨김, 실제 파일 충돌 거절·원본 백업을 검사했습니다. 다섯 전공의 41주 검사도 미니게임을 정상 명령으로 푼 뒤 진행합니다. 게임 보안 빌드와 편집기 빌드를 별도로 확인했고 로컬 편집기 HTTP 200을 확인했습니다. 신규 화면의 실제 브라우저 배치·초보자 이해도 검증은 아직 남아 있습니다.

아래 최초 튜토리얼 완주·반응형 확인은 앞선 버전에서 수행한 기록입니다. 이후 확장한 과목·튜토리얼 판정·주간 검토는 새 회귀 테스트와 빌드로 검사했으며 추가 자동 브라우저 조작은 크레딧 제한으로 수행하지 않았습니다.

Google 계정 선택은 사용자가 직접 수행했습니다. 이후 실제 로그인 세션과 로컬 게임 서버를 사용해 다음을 확인했습니다. 인증 토큰·계정 식별자는 이 문서에 기록하지 않습니다.

- 튜토리얼 단원을 순서대로 잠그지 않고 이동·실습, 8개 단원 완료
