# 학교 이야기 추가·수정

`data/chapters.json`은 장면 ID를 키로 하는 객체입니다. 각 장면은 발생 주차(`week`, 0~41), 제목·장소, 대화 페이지(`speaker`, `text`), 마지막에 연결할 메뉴(`action`)를 가집니다. 현재는 겨울방학·3월·여름방학·9월·11월·한 해의 끝 여섯 장면입니다. 새 과제나 보상을 만드는 경로가 아닙니다.

장면별로 담당자를 정해 다른 장면을 독립적으로 수정할 수 있습니다. 새 ID는 UUID로 만들고 기존 키를 바꾸거나 재사용하지 않습니다. 같은 장면의 페이지를 함께 바꾸려면 Git에서 그 레코드의 수정 내용을 먼저 비교합니다. ID 삭제·페이지 수 축소는 저장된 읽기 위치를 깨뜨릴 수 있으므로 구버전 변환 없이 적용하지 않습니다.

대사의 `when`은 `src/domain/story.js`의 조건 ID를 참조하며 `otherwise`를 함께 둡니다. 현재 `thesisComplete`, `essayComplete`, `anyAdmission`이 있고 실제 저장 결과로 분기합니다. 새 조건은 도메인에 등록하고 `chapterIssues` 검사를 갱신합니다. 브라우저에서 임의 JavaScript나 HTML을 실행하는 방식은 지원하지 않습니다.

읽는 위치·넘김 상태는 `story` 저장 필드에 장면별로 보존됩니다. UI는 `story {chapter,action:next|skip}` 명령만 요청하고 서버가 주차·범위·revision·중복을 검증합니다. 종료 후에도 기록에서 읽을 수 있습니다. 최초 생성 때 인트로를, 주간 결과를 닫을 때 그 주차 장면을 열며 언제든 닫을 수 있습니다. 이야기를 다 읽어야 공부·스터디·과제를 할 수 있는 조건은 없습니다.

기록의 ‘학교 이야기’에서 다시 읽습니다. 서사는 주간 능력치 변화 로그에 섞지 않습니다. 그림·색은 기존 기숙사와 공통 종이색 테마를 사용합니다. 문구·저장 계약을 바꾼 뒤 `npm run check`, `npm test`, 보안 빌드를 실행하고 CONTENT_VERSION·구버전 호환을 함께 확인합니다.
