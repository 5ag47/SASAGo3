과목 json 정리 관련
일단 이벤트 분류 기준은
1. 범위 
- 과목별: 그 과목 수강신청 했을때 나오는거
- 공통: 그냥 다나옴
2. 진행 방식 
- 과제: 몇 번의 자습시간을 할당해서 투자해야 해결 가능, 진척도 존재
- 시험: 정기고사, 퀴즈 등 발생 시점의 능력치로 평가
- 선택: 그냥 고르면 뭔가 발생함 (수강신청, 행사 참여)
- 자연발생: 불가피함 (호실점검 등) -> 근데 얘네도 이전까지 행적에 따라 결과가 달라지긴 하겠지

이벤트별로 매개변수...생각나는것들
1. 기본 정보
- ID
- 이름 및 설명 (플레이어에게 표시)
- 관련 과목
2. 발생 조건
- 타이밍
- 확률
- 만족해야 하는 조건
- 반복?
3. 진행 조건(과제형 이벤트)
- 투자해야 하는 시간
- 마감일
4. 선택지(선택형 이벤트)
- 선택별 비용, 결과
5. 결과
- 스탯 변화
- 실패 시 불이익
- 성적 산출 방식, 랜덤성(시험터짐) (시험형 이벤트)
- 보상?

그리고, 과목을 정리한 json파일도 있어야겠지

- ID
- 이름 및 설명
- 학점 수
- 선이수 제도, 졸업요건 등 복잡한 정보?

- 어떤 수행평가가 있는지
- 반영 비율
