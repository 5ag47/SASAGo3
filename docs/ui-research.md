# 게임 UI 조사와 적용

## 목표와 판단 기준

처음 보는 플레이어가 목표·누를 곳·예상 결과를 파악할 수 있어야 합니다. 모든 행동을 임의의 순서로 잠그지 않습니다. 동시에 초반에 선택지만 나열하지 않고, 겨울방학 한 주를 실제 실습으로 제공합니다.

## 연구에서 확인한 내용

1. **Andersen 외, CHI 2012 — The Impact of Tutorials on Games of Varying Complexity.** 3개 게임, 45,000명 이상을 대상으로 튜토리얼 유무·맥락·자유도·도움말을 비교했습니다. 튜토리얼 효과는 게임 복잡도에 따라 달랐고, 특정 행동을 강제하는 방식이 유리하다는 근거는 확인되지 않았습니다. 이를 ‘튜토리얼이 불필요하다’거나 ‘아무 설명도 하지 말라’는 결론으로 일반화하지 않습니다. 이 게임에는 단기 과제와 맥락 안의 연습, 다시 열 수 있는 안내를 적용합니다. [연구진 공개 논문](https://grail.cs.washington.edu/projects/game-abtesting/chi2012/chi2012.pdf)
2. **Desurvire·Wiberg, HCI 2009 — PLAY.** 상태 표시, 일관된 조작·용어, 즉각적 피드백, 맥락에 맞는 도움, 다양한 플레이 방식과 통제감 등을 평가 기준으로 제안합니다. 휴리스틱은 설계 점검 기준이며 이 게임의 학습 효과를 직접 입증한 결과는 아닙니다. [저자 공개 논문](https://userbehavioristics.squarespace.com/s/DesigningBetterGames-09HCI-Desurvire.pdf)

## 겨울방학 튜토리얼

8개 단원: 과목·능력치 / 자습 / 과제·마감 / 회복 / 스터디 알림 / 용돈·매점 / 학사·시험 / 주간 결과.

- 각 단원은 실제 메뉴의 이름·위치와 할 행동을 안내합니다. 안내창에서 달력·패널을 대신 열지 않고 플레이어가 게임 HUD에서 직접 찾아 열어야 방문을 확인합니다. 일반 메뉴와 단원 순서는 잠그지 않습니다.
- 수학 자습과 두 칸짜리 보고서를 첫 주에 연습합니다. 연습 과제 미완료에는 불이익이 없습니다.
- 시간표를 직접 바꾸는 행동을 확인합니다. 단순히 설명 화면을 모두 넘긴 것을 모든 실습 완료로 취급하지 않습니다.
- 단원 순서를 바꿀 수 있으며, 도움말에서 다시 볼 수 있습니다. 활동·메뉴·주간 진행을 튜토리얼 순서로 잠그지 않습니다.
- 이후 발생하는 졸논·자소서 등의 과제는 익힌 ‘시간 배정→진척→마감’ 조작을 그대로 사용합니다.

## 아직 검증되지 않은 것

자동 테스트와 브라우저 QA는 기능 동작을 확인합니다. 초보자의 이해도·기억·만족도를 증명하지는 않습니다. 개발에 참여하지 않은 사람에게 다음을 안내 없이 시켜 첫 클릭, 망설임, 실수, 질문을 기록해야 합니다.

1. 수학 공부를 원하는 요일의 자습 한 칸에 신청한다.
2. 연습 보고서 두 칸과 휴식 한 칸을 원하는 순서로 편성한다.
3. 스터디 공고와 매점 가격을 확인한다.
4. 시험 주차를 찾고 한 주를 진행한다.
5. 결과에서 능력치 변화와 자동 완료를 확인한다.
6. 다음 주의 새로운 과제에 같은 방법으로 시간을 배정한다.

이 실제 첫 사용 결과를 바탕으로 안내량과 버튼 표현을 조정합니다.
